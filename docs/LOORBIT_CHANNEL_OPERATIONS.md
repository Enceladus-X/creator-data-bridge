# Loorbit 숏폼 채널 운용 방침

- 문서 상태: 시행
- 버전: 1.0
- 최초 작성일: 2026-07-12
- 적용 채널: YouTube Shorts, Instagram Reels, TikTok, X
- 다음 정기 검토: 누적 콘텐츠 12편 도달 시 또는 2026-08-09 중 빠른 시점

## 1. 목적

Loorbit는 Blender·3D 물리 시뮬레이션을 짧고 직관적인 비교 영상으로 전달한다. 채널 운용의 1차 목적은 단기 조회수 극대화가 아니라 다음 세 가지를 달성하는 것이다.

1. 여러 소재에 반복 적용할 수 있는 숏폼 포맷을 찾는다.
2. 플랫폼별 시청자 반응을 비교 가능한 방식으로 축적한다.
3. 조회를 구독·재방문·공유로 전환할 수 있는 채널 정체성을 만든다.

## 2. 현재 기준선

2026-07-12 스냅샷 기준으로 4개 플랫폼에서 15개 콘텐츠가 수집되었다.

| 플랫폼 | 수집 콘텐츠 | 확인된 초기 성과 | 현재 판단 |
| --- | ---: | --- | --- |
| YouTube | 4 | 개별 콘텐츠 조회수 합계 4,023, 3편이 1,000회 이상 | 주력 실험 플랫폼 |
| Instagram | 4 | 좋아요 합계 17, 최고 8 | 보조 성장 플랫폼 |
| TikTok | 4 | 모든 콘텐츠 0뷰 | 배포 상태 진단 우선 |
| X | 3 | 조회수 합계 12, 반응 0 | 커뮤니티 접점용 실험 플랫폼 |

현재 가장 강한 소재는 `1 face → 262,144 faces`와 같이 복잡도가 상승하며 현실감의 임계점을 보여주는 형식이다. `1kg vs 1000kg`처럼 극단적인 물리량을 비교하는 형식도 보조 축으로 유지한다.

이 기준선에는 다음 한계가 있다.

- Instagram 조회수가 수집되지 않았다.
- YouTube 좋아요는 부분 수집이며, 개별 조회수 합계와 채널 요약 조회수가 일치하지 않는다.
- 공유, 저장, 평균 시청시간, 완주율 데이터가 대부분 없다.
- X의 프로필 게시물 수와 수집된 콘텐츠 수가 일치하지 않는다.
- 플랫폼별 조회수 정의가 다르므로 원시 조회수를 직접 비교하지 않는다.

## 3. 핵심 운용 원칙

### 3.1 같은 아이디어, 다른 포장

하나의 워터마크 없는 마스터 영상을 여러 플랫폼에 사용할 수 있다. 다만 첫 장면, 화면 문구, 제목, 캡션, 질문, 음원은 각 플랫폼의 사용 맥락에 맞게 조정한다.

### 3.2 개별 영상이 아니라 묶음으로 판단

영상 한 편의 성공이나 실패로 포맷을 폐기하지 않는다. 같은 가설을 최소 3편에서 시험하고, 기본 전략 평가는 12편 단위로 한다.

### 3.3 한 번에 변수 하나만 변경

비교 실험에서는 소재, 첫 1초, 길이, 자막, 음원, 결말 중 한 요소만 의도적으로 변경한다. 여러 요소를 동시에 변경한 영상은 탐색용으로 분류하고 인과 판단에 사용하지 않는다.

### 3.4 고정 시점으로 측정

게시 직후의 숫자에 반응하지 않는다. 기본 비교 시점은 게시 후 24시간과 7일이다. 1시간 지표는 0뷰, 게시 실패, 처리 지연 같은 이상 감지에만 사용한다.

### 3.5 `0`, 누락, 지연을 구분

수집 불가나 지연된 지표를 0으로 간주하지 않는다. 플랫폼 앱, 공개 게시물, Creator Analytics, Creator Data Bridge가 서로 다를 때는 차이를 기록하고 결론을 보류한다.

### 3.6 편법보다 학습 가능한 데이터

조회수·팔로워 구매, 참여 품앗이, 무차별 맞팔, VPN·프록시를 통한 지역 위장, 동일 영상의 반복 삭제·재업로드를 사용하지 않는다. 이런 행동으로 생긴 결과는 콘텐츠 개선에 사용할 수 없는 데이터다.

## 4. 콘텐츠 체계

### 4.1 핵심 시리즈

#### A. 복잡도 상승 — 주력

- 예: `1 → 64 → 4,096 → 262,144 faces`
- 핵심 질문: 어느 단계부터 진짜처럼 보이는가?
- 시청 동기: 변화, 임계점, 큰 숫자, 만족스러운 결말

#### B. 극단 물리 비교 — 보조

- 예: `1kg vs 1000kg`, 느린 충돌 vs 빠른 충돌
- 핵심 질문: 어느 충격이 가장 만족스러운가?
- 시청 동기: 대비, 파괴, 예상과 실제 결과의 차이

#### C. 재질·조건 임계점 — 탐색

- 예: 마찰, 탄성, 두께, 감쇠, 중력, 솔버 반복 횟수 변화
- 핵심 질문: 설정 하나가 결과를 어디까지 바꾸는가?
- 시청 동기: 원인과 결과, 의외성, 학습 가치

#### D. 제작 과정 — 관계 형성

- 예: 실패 장면, 노드·설정값, 렌더 전후, 제작 시간
- 주 사용처: Instagram, X, 향후 YouTube 커뮤니티
- 목적: 완성 영상만으로 전달하기 어려운 제작자 정체성 강화

### 4.2 기본 영상 구조

1. `0~1초`: 가장 강한 결과 또는 극단적인 대비를 먼저 보여준다.
2. `1초 이후`: 숫자나 조건이 상승하는 과정을 즉시 시작한다.
3. 중간: 설명보다 화면 변화로 이해시킨다. 불필요한 정지 구간을 제거한다.
4. 결말: 결과를 완전히 보여준 뒤 선택 가능한 질문을 제시한다.
5. 마지막 프레임: 첫 프레임과 자연스럽게 연결될 수 있으면 루프로 설계한다.

화면 문구는 영어를 기본으로 하되, 소리 없이 보아도 조건과 결과를 이해할 수 있어야 한다. 질문은 `What looked real?`보다 `64, 4K, or 262K?`처럼 답하기 쉽게 만든다.

### 4.3 제목과 캡션 원칙

- 구체적인 숫자와 변화 결과를 앞쪽에 둔다.
- 해시태그만 나열하지 않는다.
- 영상에서 이미 보이는 내용을 장황하게 반복하지 않는다.
- 질문은 한 개만 사용한다.
- 플랫폼 간 동일 문구를 기계적으로 복제하지 않는다.
- 해시태그는 관련성이 높은 소수만 사용하고 성과의 주된 원인으로 간주하지 않는다.

## 5. 플랫폼별 역할

### 5.1 YouTube Shorts — 주력 실험실

- 우선순위 1순위다.
- 구독자 수와 관계없이 개별 콘텐츠가 추천되는 기회를 활용한다.
- 공개 조회수보다 `Engaged views`, `How many chose to view`, 평균 시청시간, 평균 시청률, 영상별 구독자 증가를 우선 평가한다.
- 1,000~2,000회에서 멈춘 영상은 실패로 삭제하지 않고 초기 테스트 결과로 보존한다.
- 동일 영상을 제목만 바꾸어 반복 업로드하지 않는다.

### 5.2 Instagram Reels — 공유·저장 검증

- 비팔로워 도달, 공유, 저장을 핵심 지표로 본다.
- 질문형 캡션과 제작 과정 콘텐츠를 함께 활용한다.
- 프로페셔널 계정을 유지하고 Account Status의 추천 자격을 정기 확인한다.
- 피드에는 채널 소개, 대표 시리즈, 제작 방식이 보이도록 핵심 게시물을 고정한다.

### 5.3 TikTok — 진단 후 재개

- 4개 연속 0뷰의 원인이 확인되기 전에는 게시 빈도를 늘리지 않는다.
- Account Check, For You 추천 자격, 공개 상태, 다른 계정에서의 재생 여부, 앱 Analytics와 수집 데이터의 차이를 확인한다.
- 상태가 정상이라면 워터마크 없는 원본을 TikTok 앱에서 직접 올린 신규 영상 한 편으로 재시험한다.
- 재시험 영상이 24시간 후에도 0뷰이면 콘텐츠 개선 문제가 아니라 계정·배포·수집 문제로 분류한다.
- 0뷰 영상을 같은 날 반복 삭제·재업로드하지 않는다.

### 5.4 X — 대화와 제작자 네트워크

- 완성 영상 단독 게시의 우선순위는 낮춘다.
- Blender, simulation, VFX 관련 제작자 대화에 의미 있는 답글과 제작 정보를 제공한다.
- 영상과 함께 설정값, 실패 원인, 선택형 질문을 작성한다.
- 팔로워와 관계망이 형성되기 전에는 조회수를 콘텐츠 품질 지표로 사용하지 않는다.

## 6. 게시 빈도

품질과 측정 가능성을 유지할 수 있는 범위에서 다음을 기본값으로 사용한다.

| 플랫폼 | 기본 빈도 | 비고 |
| --- | --- | --- |
| YouTube | 주 5편 이내, 하루 최대 1편 | 핵심 시리즈 우선 |
| Instagram | 주 4~5편, 하루 최대 1편 | Reels와 제작 과정 혼합 |
| TikTok | 진단 완료 전 추가 게시 중지 | 정상화 후 하루 1편으로 재개 |
| X | 주 2~3개 원본 게시물 | 관련 대화 참여를 별도로 수행 |

제작 품질이 떨어지거나 실험 변수 기록이 불가능해지면 빈도를 낮춘다. 예약 시간보다 일관된 품질과 고정된 측정 시점이 우선이다.

## 7. 12편 실험 주기

다음 12편은 아래와 같이 구성한다.

| 시리즈 | 편수 | 주요 실험 변수 |
| --- | ---: | --- |
| 복잡도 상승 | 4 | 단계 수, 숫자 표시, 현실감 질문 |
| 극단 물리 비교 | 4 | 질량·속도·재질, 첫 충돌 장면 |
| 재질·조건 임계점 | 4 | 마찰·탄성·두께·감쇠 |

각 영상에는 다음 식별자를 부여한다.

```text
concept_id: complexity | impact | material
episode_id: 숫자
hook_variant: A | B | C
master_asset: 원본 파일명
```

12편이 끝나면 다음 순서로 판단한다.

1. 플랫폼별 24시간·7일 중앙값을 계산한다.
2. 조회수뿐 아니라 시청 유지, 공유·저장, 구독 전환을 함께 확인한다.
3. 자기 플랫폼 중앙값의 2배 이상을 반복 달성한 구조는 확대한다.
4. 중앙값 부근의 구조는 첫 1초나 결말만 바꾸어 한 주기 더 시험한다.
5. 3회 이상 시험했는데 계속 중앙값의 절반 미만인 구조는 보류한다.

위 기준은 절대적인 알고리즘 임계값이 아니라 채널 내부 의사결정 규칙이다. 데이터가 불완전한 플랫폼에는 적용하지 않는다.

## 8. 측정 항목

### 게시 시 기록

- 플랫폼과 콘텐츠 URL
- 게시 시각과 표준시간대
- `concept_id`, `episode_id`, `hook_variant`
- 영상 길이
- 제목·캡션·해시태그
- 사용 음원과 업로드 방식
- 원본 파일명

### 게시 후 기록

| 플랫폼 | 우선 지표 |
| --- | --- |
| YouTube | Engaged views, 시청 선택률, 평균 시청시간, 평균 시청률, 구독자 증가 |
| Instagram | 도달, 비팔로워 도달 비율, 평균 시청시간, 공유, 저장, 팔로우 증가 |
| TikTok | 조회수, For You 유입 비율, 평균 시청시간, 완주율, 추천 자격 |
| X | 노출, 미디어 조회, 답글, 재게시, 프로필 방문 |

모든 플랫폼에서 24시간과 7일 수치를 동일한 열 구조로 보존한다. 수집할 수 없는 값은 빈칸과 coverage 상태로 남기며 0으로 채우지 않는다.

## 9. 이상 상황 대응

### TikTok 0뷰

1. 게시 후 1시간 동안 처리 중인지 확인한다.
2. 24시간 후에도 0이면 Account Check와 추천 자격을 확인한다.
3. 로그아웃 상태 또는 다른 계정에서 게시물이 보이는지 확인한다.
4. 앱 Analytics와 Creator Data Bridge 값을 비교한다.
5. 정상 상태가 확인된 뒤에만 새로운 원본으로 한 번 재시험한다.

### Instagram 비팔로워 도달 0

1. 계정이 공개 상태인지 확인한다.
2. Account Status에서 추천 불가 항목을 확인한다.
3. 조회수와 좋아요가 아니라 비팔로워 도달을 직접 확인한다.
4. 정상 상태라면 관련 제작자와의 진정성 있는 상호작용 및 포맷 개선을 진행한다.

### YouTube 조회수 정체

1. 공개 조회수 대신 Engaged views와 시청 선택률을 확인한다.
2. 첫 1초 이탈과 평균 시청률을 비교한다.
3. 소재 수요와 경쟁도가 다른 영상인지 확인한다.
4. 삭제·재업로드하지 않고 다음 영상의 가설에 반영한다.

### 데이터 불일치

1. 각 지표의 기간과 집계 화면을 확인한다.
2. 공개 카운터, Creator Analytics, 수집 도구의 출처를 구분한다.
3. 지연 또는 부분 수집으로 표시하고 비율 계산에서 제외한다.

## 10. 검토 주기

- 게시 당일: 게시 성공과 이상 여부만 확인한다.
- 매주: 24시간 기준 성과와 제작 부담을 검토한다.
- 12편마다: 시리즈별 성과와 포맷 우선순위를 조정한다.
- 매월: 플랫폼별 투자 시간, 구독 전환, 데이터 수집 품질을 검토한다.

성과가 좋지 않은 주에도 즉흥적으로 채널 정체성을 바꾸지 않는다. 단, 계정 제한이나 0뷰 같은 기술적 이상은 즉시 진단한다.

## 11. 단계별 성공 기준

### 1단계 — 기준선 형성: 누적 30편까지

- 세 가지 핵심 시리즈의 비교 가능한 데이터 확보
- 반복 가능한 우승 포맷 최소 1개 확인
- TikTok 0뷰 문제 해결 또는 운영 중단 결정
- 플랫폼별 24시간·7일 측정 누락 최소화

### 2단계 — 확대: 우승 포맷 확인 후

- 우승 포맷을 전체 게시물의 약 60%로 확대
- 보조 포맷 30%, 신규 탐색 10% 유지
- 조회수뿐 아니라 구독·팔로우·공유 전환 개선
- 제작 시간을 줄일 수 있는 템플릿과 렌더 파이프라인 정리

### 3단계 — 채널 자산화

- 대표 시리즈 명칭과 일관된 화면 언어 확립
- 성과가 검증된 숏폼을 장문 영상, 제작기, 튜토리얼로 확장
- 플랫폼별 수익성과 장기 시청자 가치를 기준으로 투자 비중 재조정

## 12. 금지 목록

- 조회수, 좋아요, 댓글, 팔로워 구매
- 무차별 맞팔과 복사 댓글
- 참여 품앗이 그룹 사용
- 지역 타기팅을 위한 VPN·프록시 계정 운영
- 다른 플랫폼 워터마크가 포함된 영상 업로드
- 같은 플랫폼에 동일 영상을 짧은 간격으로 반복 게시
- 낮은 조회수를 이유로 성급하게 삭제
- 여러 변수를 동시에 바꾸고 하나의 원인을 단정
- 데이터 coverage를 무시한 플랫폼 간 직접 비교

## 13. 게시 전 체크리스트

- [ ] 첫 1초에 결과 또는 강한 대비가 보인다.
- [ ] 소리 없이도 비교 조건을 이해할 수 있다.
- [ ] 화면 숫자와 단위가 정확하다.
- [ ] 불필요한 정지 구간이 없다.
- [ ] 질문이 한 개이며 쉽게 답할 수 있다.
- [ ] 마스터 영상에 플랫폼 워터마크가 없다.
- [ ] `concept_id`와 실험 변수를 기록했다.
- [ ] 플랫폼별 제목과 캡션을 조정했다.
- [ ] 24시간·7일 측정 일정을 기록했다.

- 변경한 규칙
