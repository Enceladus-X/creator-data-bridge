# 제품 요구사항

## 1. 제품 정의

작업명은 **Creator Data Bridge**다. 여러 소셜 플랫폼의 내 채널 성과를 한 화면에서 동기화하고, 데이터 출처와 한계를 명시한 AI 분석용 패키지로 내보내는 Chrome 확장프로그램이다.

핵심 가치는 단순한 대시보드 복제가 아니다. 플랫폼마다 다른 이름과 집계 방식을 공통 언어로 번역하고, AI가 잘못된 비교를 하지 않도록 데이터 커버리지와 계산 근거까지 함께 제공하는 것이다.

## 2. 대상 사용자

- 여러 플랫폼에 같은 또는 유사한 콘텐츠를 올리는 1인 크리에이터
- 매주 성과를 회고하고 다음 콘텐츠를 정하는 소규모 채널 운영자
- 채널 데이터를 ChatGPT, Claude, Gemini 또는 사내 AI에 전달하려는 사용자
- 향후 여러 고객 계정을 관리할 소규모 에이전시

MVP는 단일 사용자와 본인 소유 계정에 집중한다.

## 3. 해결할 작업

### 연결

- 사용자는 비밀번호를 제품에 넘기지 않고 각 플랫폼에 로그인한다.
- 연결된 계정, 권한, 토큰 만료, 마지막 성공 동기화 시각을 확인한다.
- 계정 연결을 해제하면 토큰 폐기와 저장 데이터 삭제를 선택할 수 있다.

### 동기화

- `모두 동기화` 한 번으로 연결된 플랫폼을 병렬 수집한다.
- 기본 기간은 최근 28일이며 7일, 28일, 90일, 사용자 지정 기간을 제공한다.
- 플랫폼 API 제한 때문에 일부 기간이나 지표가 불가능하면 동기화 전에 알리고 결과에도 남긴다.
- 부분 실패가 전체 실패가 되지 않으며 플랫폼별 재시도가 가능하다.

### 분석

- 전체와 플랫폼별 성과를 모두 본다.
- 상위 콘텐츠, 게시 빈도, 조회·노출·참여 추이, 구독자 또는 팔로워 변화를 본다.
- 지표 정의와 분모가 다른 값은 억지로 합산하지 않는다.
- 플랫폼 원본 지표와 제품이 계산한 파생 지표를 시각적으로 구분한다.

### AI 전달

- 현재 화면의 기간과 필터를 그대로 AI 패키지로 만든다.
- 사람이 읽는 `summary.md`, 기계가 읽는 `metrics.json`, 콘텐츠 행 단위의 `content.csv`를 제공한다.
- 민감하거나 큰 원본 데이터는 기본 제외하고 사용자가 선택할 때만 포함한다.
- 패키지에는 누락, 추정, 표본 제한, 데이터 최신성 경고가 반드시 포함된다.

## 4. UX 구조

### 확장프로그램 액션과 사이드 패널

확장 아이콘을 누르면 사이드 패널이 열린다. 고정 폭 UI에서 다음만 빠르게 처리한다.

- 플랫폼별 연결 상태
- 기간 선택
- `모두 동기화` 버튼과 진행 상태
- 핵심 지표 4개: 조회/재생, 참여, 팔로워 순증, 게시물 수
- 마지막 동기화 및 경고
- 전체 대시보드 열기
- AI 패키지 만들기

### 전체 대시보드

확장프로그램 전용 탭에서 다음 뷰를 제공한다.

- 개요: 전체 성과와 플랫폼 비교
- 콘텐츠: 플랫폼을 넘나드는 콘텐츠 목록과 정렬
- 추이: 일별·주별 시계열
- 플랫폼 상세: 해당 플랫폼에서만 가능한 지표
- 내보내기: 포함 데이터 미리보기와 파일 생성
- 연결 관리: 권한, 상태, 데이터 삭제

## 5. 공통 지표 모델

공통 지표는 이름이 같아 보여도 의미가 다를 수 있으므로 `metric_id`, `value`, `unit`, `scope`, `source`, `method`, `coverage`를 함께 저장한다.

| 영역 | 공통 지표 | 처리 원칙 |
| --- | --- | --- |
| 계정 | 팔로워/구독자 현재값 | API 스냅샷 |
| 계정 | 기간 순증 | 플랫폼 제공값 우선, 없으면 저장 스냅샷 차이로 계산 |
| 발행 | 콘텐츠 수 | 기간 내 공개된 콘텐츠 기준 |
| 노출 | views, plays, impressions | 합산 화면에서는 별도 열로 유지 |
| 도달 | reach | 고유 사용자에 가까운 플랫폼 지표만 매핑 |
| 참여 | likes, comments, shares, saves | 제공되는 하위 항목과 합계를 함께 저장 |
| 시청 | watch time, average view duration | 제공 플랫폼에서만 표시 |
| 전환 | profile visits, link clicks, follows | 플랫폼별 정의를 보존 |

파생 지표에는 계산식을 식별하는 `formula_id`를 둔다. 예를 들어 참여율은 `engagements / impressions`와 `engagements / views`를 같은 이름으로 섞지 않고 `engagement_rate_by_impressions`, `engagement_rate_by_views`로 구분한다.

## 6. MVP 기능 우선순위

### 필수

- Chrome Manifest V3 확장프로그램
- 유튜브 OAuth 연결 및 최근 28일 동기화
- 계정, 콘텐츠, 일별 추이, 상위 콘텐츠 수집
- 공통 데이터 모델과 플랫폼 원본 보존
- Markdown, JSON, CSV AI 패키지 생성
- 동기화 이력, 부분 실패, 재시도, 데이터 최신성 표시
- 계정 연결 해제 및 데이터 삭제

### 다음

- Instagram Professional 계정 연결
- TikTok 프로필·영상 성과 연결
- X 본인 게시물과 최근 비공개 성과 연결
- 플랫폼 비교와 공통 콘텐츠 묶기
- 자동 주간 스냅샷

### 나중

- AI 공급자 직접 연결
- 예약 리포트, 팀 공유, 벤치마크
- 수익 지표와 광고 계정
- 콘텐츠 제목·설명·썸네일 기반 의미 분석

## 7. 비기능 요구사항

- 모든 토큰은 최소 권한으로 요청한다.
- 비밀키와 갱신 토큰은 확장 패키지 및 브라우저 저장소에 두지 않는다.
- 사용자가 데이터의 출처, 수집 시각, 계산식을 확인할 수 있어야 한다.
- 동기화 한 번의 목표 시간은 플랫폼 1개 기준 30초 이내다.
- 동일 요청의 재실행은 중복 행을 만들지 않아야 한다.
- 원본 API 응답 변화가 공통 스키마를 조용히 손상시키지 않도록 계약 테스트를 둔다.
- 한국어와 영어 UI 문자열을 처음부터 분리한다.

## 8. MVP 완료 기준

- 테스트 유튜브 채널을 연결하고 28일 데이터를 한 번에 가져온다.
- Studio 화면의 대표 지표와 API 결과 차이를 설명할 수 있다.
- 네트워크 또는 권한 오류 후 해당 플랫폼만 재시도할 수 있다.
- 생성된 AI 패키지만으로 AI가 상위 콘텐츠, 추이, 누락 범위를 식별한다.
- 토큰이 확장 번들, 로그, 내보내기 파일에 포함되지 않는다.
- 확장프로그램 삭제 전후의 데이터 삭제 경로가 문서화되고 작동한다.
