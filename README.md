# Creator Data Bridge

유튜브, 인스타그램, 틱톡, X의 내 계정 성과 데이터를 한 번에 동기화하고 AI가 바로 읽을 수 있는 형태로 내보내는 Chrome 확장프로그램입니다.

현재 단계는 제품 및 기술 기획입니다. 구현은 유튜브 수직 슬라이스부터 시작하되, 처음부터 플랫폼 커넥터를 교체 가능한 구조로 설계합니다.

## 제품 원칙

- 공식 API와 OAuth만 사용하고 Studio/대시보드 화면을 스크래핑하지 않습니다.
- 확장프로그램은 연결, 동기화, 확인, 내보내기의 조작면을 담당합니다.
- OAuth 비밀키와 갱신 토큰은 확장프로그램에 넣지 않고 백엔드의 암호화된 토큰 저장소에 둡니다.
- 원본 응답을 보존하면서 플랫폼 간 비교가 가능한 공통 지표를 별도로 만듭니다.
- 값이 없는 경우 `0`으로 꾸미지 않고 `unsupported`, `unavailable`, `thresholded`를 구분합니다.
- AI 전송은 사용자 확인을 거친 내보내기부터 시작합니다. 자동 외부 전송은 후속 기능입니다.

## 첫 사용자 흐름

1. 확장프로그램을 설치하고 플랫폼 계정을 OAuth로 연결합니다.
2. 기간을 선택하고 `모두 동기화`를 누릅니다.
3. 플랫폼별 수집 범위와 누락 경고를 확인합니다.
4. 공통 성과, 상위 콘텐츠, 기간 추이를 확인합니다.
5. `AI 패키지 만들기`를 눌러 Markdown, JSON, CSV 묶음을 생성합니다.
6. 원하는 AI에 파일을 첨부하거나 요약문을 복사합니다.

## MVP 범위 밖

- 게시물 작성, 예약 발행, 댓글 및 DM 관리
- 경쟁 채널 또는 비연결 계정의 데이터 수집
- 로그인 쿠키, 페이지 DOM, 비공개 엔드포인트를 이용한 스크래핑
- 사용자의 확인 없는 제3자 AI 서비스 자동 전송
- 광고 캠페인 통합과 팀·에이전시용 다중 조직 관리
