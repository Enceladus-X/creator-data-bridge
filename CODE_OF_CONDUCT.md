# Community Code of Conduct

## Our standard

Creator Data Bridge welcomes contributors with different backgrounds and levels of experience. We want project spaces to remain practical, respectful, and safe for everyone.

Examples of positive participation include:

- Giving technical feedback about the work rather than the person
- Sharing enough context to make bugs and proposals reproducible
- Respecting platform users, creator privacy, and service policies
- Accepting corrections and acknowledging uncertainty
- Helping newcomers understand project conventions

Unacceptable behavior includes:

- Harassment, threats, discrimination, or sexualized language
- Publishing another person's private information without permission
- Sharing access tokens, account credentials, private channel data, or unredacted fixtures
- Deliberately disrupting discussions, reviews, or project infrastructure
- Encouraging platform abuse, authentication bypass, or deceptive automation

## Scope

This code applies to repository issues, pull requests, discussions, reviews, and other spaces where someone represents the project.

## Reporting

For ordinary conduct concerns, contact the repository owner through a private GitHub channel. For vulnerabilities, credential exposure, or account-security concerns, use GitHub Security Advisories as described in [SECURITY.md](SECURITY.md). Do not include sensitive account data in a public issue.

## Enforcement

Maintainers may edit or remove contributions that violate this code and may temporarily or permanently restrict participation when necessary. Enforcement decisions should be proportional, documented privately when appropriate, and focused on protecting the community and project users.
